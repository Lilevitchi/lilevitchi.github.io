# Préparation & installation

Cette section permet de partir sur une base **saine et propre** avant toute installation de mods.

---

## Installer les redistribuables Visual C++

<div class="custom-card">
🧩 **Indispensable**
</div>

La majorité des outils et mods nécessitent les redistribuables Visual C++ les plus récents.

### Étapes

1. Téléchargez le pack **VC++ AIO**
2. Extrayez l’archive
3. Lancez `install_all.bat` en tant qu’administrateur
4. Redémarrez votre PC

<div class="bot-advice">
💡 Même si vous pensez déjà les avoir installés, refaites l’opération.  
Les versions manquantes sont une cause fréquente de crash.
</div>

---

## Afficher les extensions de fichiers

Windows masque par défaut les extensions de fichiers, ce qui complique fortement le modding.

### Étapes

1. Ouvrez l’explorateur de fichiers
2. Onglet **Affichage**
3. Activez **Extensions de noms de fichiers**

<div class="bot-advice">
💡 Savoir si un fichier est `.exe`, `.dll`, `.esp` ou `.ini` est essentiel pour éviter les erreurs.
</div>
